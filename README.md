# Foundry

[![npm version](https://badge.fury.io/js/%40foundry-ds%2Fcore.svg)](https://www.npmjs.com/package/@foundry-ds/core)

An open source design system generator for product designers and frontend engineers.

Pick an accent color. Get a complete, accessible token system —
ready for Figma, CSS, Tailwind, W3C DTCG, and production code.

## The core idea

Most design systems are tied to one framework.
Foundry's token engine is framework-agnostic by design.

The same `dist/tokens.css` generated by `@foundry-ds/core` powers:
- A **React** app (packages/web) using Tailwind + shadcn/ui
- An **Angular** app (packages/angular-demo) using SCSS

Zero changes to the engine. One token contract, multiple frameworks.

---

## How it works

```
You pick an accent color + WCAG accessibility level
  ↓
@foundry-ds/core generates 6 color families × 11 shades
Color harmony shifts semantic colors toward your accent hue
  ↓
Every shade is checked for WCAG contrast compliance
Failing shades get the closest accessible alternative suggested
  ↓
Export as CSS variables · Tailwind config · tokens.json · W3C DTCG
```

---

## Color harmony

Foundry's semantic colors (success, warning, error, info) shift
subtly toward your accent hue while keeping their universal meaning.
A purple brand gets a slightly warmer green success and shifted red error —
the whole palette feels cohesive without losing semantic clarity.

Maximum hue shift is capped at 15° so green always reads as success,
red always reads as error, regardless of brand color.

## Getting started

```bash
# Install all dependencies
yarn install

# Start the React web app
yarn dev:web

# Start the Angular demo
cd packages/angular-demo && ng serve

# Build the token CSS
yarn build:tokens

# Run all tests
cd packages/core && yarn test
```

## Why this exists

Built by a product designer who spent years maintaining fragmented
design systems across multiple products — and eventually started
writing the production code herself.

The color system architecture comes from real work: migrating
a multi-product SaaS platform from inconsistent RGB values to a
formulaic HSL system that generates consistent, accessible palettes
on demand with color harmony across the whole token set.
