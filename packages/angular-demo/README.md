# Foundry — Angular Demo

**Live demo:** https://foundry-angular-demo.vercel.app/

Proof that Foundry's token system is framework-agnostic.

The same `dist/tokens.css` generated by `@foundry/core` that powers
the React web app drives these Angular components — with zero changes
to the engine.

---

## What this proves

Foundry's core engine outputs standard CSS custom properties.
CSS custom properties work in every browser, every framework,
every build tool. No framework-specific code needed.

```
@foundry/core (TypeScript engine)
  ↓ generates
dist/tokens.css (CSS custom properties)
  ↓ consumed by
packages/web          (React + Tailwind)
packages/angular-demo (Angular + SCSS)   ← you are here
packages/figma        (Figma plugin)     ← coming soon
```

| Component | Variants |
|---|---|
| `FoundryButton` | primary · secondary · ghost · danger · disabled · sm/md/lg |
| `FoundryBadge` | primary · success · warning · error · neutral |
| `FoundryInput` | default · error state · disabled · with hint |
| `FoundryCard` | with title and status badge |

## How to run

```bash
# From the repo root — generate the token CSS first
yarn build:tokens

# Then start the Angular dev server
cd packages/angular-demo
ng serve
```

Open `http://localhost:4200`

---

## How tokens are consumed

One import in `src/styles.scss`:

```scss
@import './foundry-tokens.css';
```

Every component then uses CSS custom properties:

```scss
// Button component
background-color: var(--color-primary-fill);
color: var(--color-primary-contrast-text);
border-color: var(--color-primary-fill);

// Input focus state
border-color: var(--color-primary-fill);
box-shadow: 0 0 0 3px var(--color-primary-bg);

// Card surface
background-color: var(--color-neutral-surface);
border: 1px solid var(--color-neutral-border);
```

## Dark mode

The theme toggle sets `data-theme="dark"` on the `<html>` element.
The CSS custom properties automatically switch to dark values —
no component code changes needed.

```typescript
// theme-toggle.component.ts
document.documentElement.setAttribute(
  'data-theme',
  this.isDark() ? 'dark' : 'light'
);
```

This works because `@foundry/core` generates both themes:

```css
:root { --color-neutral-background: #f8fafc; }
[data-theme="dark"] { --color-neutral-background: #0f172a; }
```

## Regenerating tokens

When you change the accent color in Foundry:

```bash
# Default accent (#3a5afe)
yarn build:tokens

# Custom accent color
cd packages/core
npx tsx scripts/build.ts --accent #8b5cf6

# Then copy to angular-demo
cp dist/tokens.css ../angular-demo/src/foundry-tokens.css
```
